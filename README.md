# Hall of Abstraction

A reading-focused website profiling the great thinkers who shaped how we reason, govern and live, organised by the schools of thought (ideologies) they built or belong to.

Built with [Astro](https://astro.build) as a fully static site. All content lives in Markdown files, so there's no database or server.

## Getting started

```sh
npm install
npm run dev        # local dev server at http://localhost:4321/hall-of-abstraction/
npm run build      # type-check, build to dist/, and build the search index
npm run preview    # serve the production build
```

Node 22.12 or newer is required.
